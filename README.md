# 실적분석 (중국법인 재무실적 종합 분석)

회계관리·예산관리·자금집행 세 모듈의 데이터를 종합해서 법인별 재무실적과 리스크를 보여주는
대시보드입니다. 관리부 ERP 통합시스템의 마지막(네 번째) 데이터 모듈로, 회계관리 → 예산관리 →
자금집행 → **실적분석** 파이프라인의 종착점입니다.

**이 모듈은 별도의 데이터 입력이 없습니다.** 세 모듈이 이미 저장한 데이터를 조인해서 보여주는
순수 조회/분석 대시보드이며, 새 테이블을 만들지 않습니다.

회계관리, 예산관리, 자금집행, 접대비와 동일하게 바닐라 HTML/JS/CSS + Supabase + GitHub Pages
구조입니다. Supabase 프로젝트는 회계관리/예산관리/자금집행과 **같은 관리부 ERP 전용 프로젝트를
공유**합니다 (접대비는 별도 프로젝트). 차트는 Chart.js를 vendor로 내려받아 CDN 없이
사용합니다.

## 4가지 분석 지표 (추가 지표는 추후 보완 예정)
1. **수익성 추이**: 매출/영업이익/순이익 및 영업이익률/순이익률 (회계관리 PL 데이터 기반)
2. **재무안정성**: 부채비율/유동비율 (회계관리 B/S 데이터 기반)
3. **예산 대비 실적**: 달성률 + 예산 초과 계정 목록 (예산관리 데이터 재사용)
4. **자금 위험 요약**: 시재 증감률/총 차입금잔액/배당가능금액 (자금집행 데이터 재사용)

월간 데이터를 저장하고, 화면에서 분기/연간으로 자동 집계합니다. **흐름지표(매출/이익)는 기간 내
합산, 저량지표(비율/잔액)는 기간 말월 값**을 사용합니다 (재무 원칙상 합산하면 안 되는 지표를
실수로 합산하지 않도록 프론트 로직에서 구분).

## 구성
- `docs/` — GitHub Pages로 배포되는 프론트엔드
  - `index.html` — 법인/적용년도월/접근키 입력
  - `view.html` — 읽기 전용: 4개 섹션 + 월간/분기/연간 토글 + 수익성 추이 차트
  - `admin.html` — [본사용] 전체 법인 비교 테이블 + 막대차트 + 엑셀 다운로드
- `supabase/` — 함수 정의만 (`schema.sql`, 신규 테이블 없음). **회계관리·예산관리·자금집행의
  schema.sql이 모두 먼저 적용되어 있어야** 정상 동작합니다.

## 배포 방법
`supabase/README-deploy.md`를 따라 Supabase에 함수를 적용한 뒤,
`docs/js/config.js`의 `SUPABASE_URL`/`SUPABASE_ANON_KEY`를 채우고 GitHub Pages로 배포하세요.

## 로컬 실행
```
python -m http.server 8093 --directory docs
```

## 주의: 계정코드/법인 목록 하드코딩
이 모듈의 RPC는 회계관리 플레이스홀더 계정코드와 6개 법인 목록을 하드코딩으로 참조합니다.
실제 COA 교체 또는 법인 변경 시 `supabase/README-deploy.md`를 참고해 `schema.sql`을 다시 적용하세요.
